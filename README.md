## Baby Photoshop
Baby photoshop is a C++ program for providing filters to images and modify them. all filters are using an image processing library.

### Provided Filters:
1) Grayscale Conversion
2) Black and White
3) Invert Colors
4) Merge Images
5) Flip Image
6) Rotate Image
7) Lightness of Image
8) Crop Image
9) Adding Frame to Image
10) Detect Image Edges
11) Resizing Image
12) Blur Imagese
